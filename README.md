# Gestión de Biblioteca-Guía 

## Descripción
El sistema permite administrar libros, usuarios y préstamos de una biblioteca escolar, implementando las reglas de negocio fundamentales.

## Funcionalidades

### Gestión de Libros
- Registrar libros (código, título, autor)
- Listar todos los libros
- Listar libros disponibles
- Consultar disponibilidad individual

### Gestión de Usuarios
- Registrar usuarios (ID, nombre, correo)
- Listar todos los usuarios

### Gestión de Préstamos
- Registrar préstamo de libros (con validaciones)
- Registrar devolución de libros
- Listar préstamos activos
- **EXTENSIÓN:** Fecha estimada de devolución (7 días)
- **EXTENSIÓN:** Listar préstamos vencidos
- **EXTENSIÓN:** Listar préstamos próximos a vencer
